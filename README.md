# 🎬 Cinema Booking System

Учебный дипломный проект по профессии  
**«Веб-разработчик: Backend-разработка на Python» (Нетология)**.

Проект представляет собой учебную систему онлайн-бронирования билетов в кинотеатр
с пользовательской частью и административной панелью.

---

## 🚀 Функциональность

### Пользовательская часть
- просмотр списка фильмов и сеансов
- выбор зала и мест
- бронирование и покупка билетов
- просмотр истории бронирований

### Административная часть
- управление фильмами
- управление залами и сеансами
- просмотр и архивирование бронирований

---

## 🛠 Используемые технологии

### Backend
- Python 3.11
- FastAPI
- SQLAlchemy 2
- Alembic
- PostgreSQL
- Асинхронное взаимодействие с БД

### Frontend
- React 18
- Vite
- Axios
- React Router

### Инфраструктура
- Docker
- Docker Compose

---

## 🧩 Архитектура проекта

Проект реализован как учебное клиент-серверное приложение:

- backend предоставляет REST API
- frontend взаимодействует с backend через HTTP-запросы
- данные хранятся в PostgreSQL
- миграции базы данных выполняются с помощью Alembic

---

## ⚙️ Запуск проекта локально

### 1. Клонирование репозитория
```bash
git clone https://github.com/zvezda1207/Cinema-diplom.git
cd Cinema-diplom
```

### 2. Запуск через Docker Compose

```bash
docker compose up --build
```
После запуска доступны:

- Backend: http://localhost:8000
- Swagger UI: http://localhost:8000/docs
